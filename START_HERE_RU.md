# Запуск версии с LAB 11

В приложении есть кнопка **Notes** справа сверху рядом с корзиной: Dark mode, Display name / Save name и заметки.

Для Chrome запускай из этой папки:

```powershell
powershell -ExecutionPolicy Bypass -File .\run_web.ps1
```

Фиксированный порт этого проекта: **7358**. Не меняй адрес и не очищай данные браузера во время проверки сохранения. Отладочный профиль Chrome хранится в `.dart_tool`; `flutter clean` или удаление этой папки может удалить веб-данные отладки. Для основной защиты используй телефон/эмулятор.

Для телефона/эмулятора:

```powershell
flutter pub get
flutter run
```

Проверка force-kill и объяснение кода — в **LAB11_RU.md**. Для обновления с сохранением текущих данных сначала прочитай UPDATE_RU.md.

# Как открыть обновлённый SneakShop

1. Распакуй архив в отдельную папку. Предыдущий архив оставь как резервную копию.
2. В Android Studio выбери File → Open → папку SneakShop_Connection_Fixed с pubspec.yaml.
3. Открой Terminal: Alt + F12.
4. Если старое приложение работает, сначала нажми q.
5. Выполни:

```sh
flutter pub get
flutter run -d chrome
```

Для Android выбери эмулятор и нажми Run на lib/main.dart.
В этой версии добавлена зависимость для определения соединения, поэтому нужен полный
перезапуск с flutter pub get; обычного Hot Reload недостаточно.

Теперь LAB 10 находится на главной. Отдельного Sneaker Drops и локального режима нет.
Дождись загрузки шести товаров. Проверь List/Grid, поиск, фильтры Men/Women,
избранное, детали, размер и корзину.

Обновление загружает каталог через интернет и добавляет следующий ещё не показанный
товар в начало. Свайп справа налево работает в List view; UNDO возвращает карточку.
Reset Catalog заново запрашивает исходные шесть товаров с сервера.

Для проверки интернета в Chrome: F12 → Network → Offline → Refresh в приложении.
Появится ошибка с Retry Connection. Верни No throttling → Retry.
На телефоне выключи Wi-Fi и мобильные данные: главный каталог должен показать ошибку.
Подключение восстанавливает загрузку. Если браузер не прислал событие отключения,
нажми Refresh. Уже выбранная корзина и избранное сохраняются между перезапусками.

Проверка проекта на твоём компьютере:

```powershell
.\check_project.ps1
```

Здесь Flutter SDK отсутствует, поэтому компиляция и прохождение Flutter-тестов пока не подтверждены.

Pull-to-Refresh на компьютере: сначала прокрути каталог к самому верху, затем
зажми левую кнопку мыши на области карточек и протяни вниз примерно на 150–250 px,
после чего отпусти. Подожди завершения индикатора. Простое вращение колеса мыши
не заменяет этот жест. На телефоне — аналогичный жест пальцем.

Исправление проверки сети: приложение теперь самостоятельно проверяет доступность
сервера каждые 5 секунд, пока открыто. После отключения сети подожди несколько секунд;
если запрос зависнет, короткая проверка ждёт до 3 секунд. Основной запрос имеет
таймаут 10 секунд. При возвращении в приложение соединение проверяется сразу.

Открывай именно папку SneakShop_Connection_Fixed из нового архива. В старом терминале
сначала нажми q и закрой старую вкладку сайта. Затем в НОВОЙ папке:

```sh
flutter pub get
flutter run -d chrome
```

Для проверки в Chrome: F12 → Network → Offline, затем Refresh внутри приложения
или подожди фоновую проверку. Верни No throttling для восстановления.
Авиарежим Windows может не отключить Wi-Fi, а Ethernet продолжает работать отдельно.
