# Запуск SneakShop

Распакуй архив и открой папку с `pubspec.yaml` в Android Studio.

Для Android открой эмулятор и выполни:

```powershell
flutter pub get
flutter run
```

Для запуска в Chrome на Windows:

```powershell
powershell -ExecutionPolicy Bypass -File .\run_web.ps1
```

В Chrome разреши доступ к камере и местоположению по запросу приложения.
Для фотожурнала в Android Emulator выбери Webcam0 в настройках Front и Rear.
Координаты для проверки можно выставить в Extended Controls → Location.

Каталог кроссовок загружается из интернета. Создать аккаунт и войти можно через Profile.
После успешного входа откроется каталог. Кнопка Notes находится вверху справа.
При обновлении существующей папки смотри UPDATE_RU.md.
